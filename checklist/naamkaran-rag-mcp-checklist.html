Naamkaran: fast search, grounded AI

The site has two paths. The fast path answers every filter and "sounds like" search instantly, with no AI involved. The smart path uses RAG and an MCP server only when someone asks a free-form question. Keeping them separate is what makes the site feel fast.

Your ticks are saved.

Fast path — filters & "sounds like"

Target: results in under 100 ms
  1. Visitor picks gender, feeling, language
  2. Browser filters a pre-built names file already downloaded
  3. Phonetic keys were computed at build time, so matching is instant
  4. List updates as they type

"A girl's name that sounds like Mia" → Maya, Mira

Smart path — RAG through MCP

Target: first words in under 1.5 s, done in under 5 s
  1. Visitor types a question in plain words
  2. MCP tool searches the names database by meaning
  3. Claude answers using only the names it got back
  4. Page shows those names from the verified data

"A Telugu name about the first rain, for a boy, not too long"

What these words mean
RAG
Retrieval-augmented generation. Before the AI answers, you look up relevant records in your own data and hand them to it, so it answers from facts you've checked instead of from memory.
MCP
Model Context Protocol. A standard way to give an AI model tools, like "search names". You build an MCP server once, and Claude (and other AI apps) can call its tools.
MCP tool
One function your server offers, with a name, a description, and a list of inputs. Example: search_names(query, gender, language).
Embedding
A list of numbers representing the meaning of a piece of text. Texts with similar meanings get similar numbers, so "first rain" can find Saavan, the monsoon month, even though the words don't match.
Vector database
A database that stores embeddings and finds the closest ones quickly. For this project, Postgres with the pgvector add-on is enough.
Hybrid search
Combining ordinary keyword search with meaning search, then applying filters like gender and language.
Reranking
A second, more careful scoring pass over the top results to put the best ones first.
Grounding
Making sure every name the AI shows actually exists in your data, with your verified meaning.
Latency
How long a visitor waits. p95 means "95% of requests were at least this fast".
CDN
Content delivery network. Copies of your files stored near visitors around the world so they download quickly.
